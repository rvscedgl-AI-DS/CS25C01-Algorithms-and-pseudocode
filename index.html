Surface Area of a Cuboid
▾
📝 Problem
Read length, breadth, and height of a cuboid and display its surface area.
🧠 Algorithm
1. Start the procedure. 2. Ask the user to enter the length, breadth, and height of the cuboid. 3. Multiply length and breadth to get the first product (lb). 4. Multiply breadth and height to get the second product (bh). 5. Multiply height and length to get the third product (hl). 6. Add the three products together and multiply the sum by 2 to compute the surface area. 7. Display the computed surface area to the user. 8. End the procedure.
💻 Pseudocode
BEGIN READ length, breadth, height lb ← length × breadth bh ← breadth × height hl ← height × length SA ← 2 × (lb + bh + hl) DISPLAY SA END
✅ Sample Input / Output
Input: length = 10, breadth = 5, height = 4 Output: Surface Area = 220

▾
📝 Problem
Read a positive number N and display all numbers from 1 to N.
🧠 Algorithm
1. Start the procedure. 2. Ask the user to enter a positive number N. 3. Initialize a counter i to 1. 4. Repeat the following steps as long as i is less than or equal to N: a. Display the current value of i. b. Increase i by 1. 5. End the procedure.
💻 Pseudocode
BEGIN READ N i ← 1 WHILE i ≤ N DO DISPLAY i i ← i + 1 END WHILE END
✅ Sample Input / Output
Input: N = 5 Output: 1 2 3 4 5

🧠 Algorithm
